# Matérias Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Página Matérias (abas Cursando / Já cursadas) com API Flask + MySQL do XAMPP.

**Architecture:** Flask (`backend/app.py`) serve `frontend/` como estático e a API `/api/materias` (blueprint). PyMySQL com cursores dict. Frontend em scripts clássicos como no Dashboard.

**Tech Stack:** Python 3.14, Flask 3, PyMySQL, pytest; MySQL/MariaDB do XAMPP; JS puro; `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-13-materias-design.md`

## Global Constraints
- Sem emojis; ícones SVG inline; tema escuro com os tokens de `style.css`.
- Mensagens de erro da API em português, formato `{"erro": "..."}`.
- Validação: nome 1–80 após trim; semestre `^\d{4}\.[12]$`; cor `^#[0-9a-fA-F]{6}$`; status `cursando|cursada`.
- Config do banco por env `DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME` com padrão `localhost, 3306, root, "", estudos`.
- Testes de API usam `DB_NAME=estudos_test`; são pulados se o MySQL não responder.

## Review Focus
- MySQL desligado → API responde 503 com mensagem clara; página mostra erro com "Tentar de novo", sem travar.
- Nome com espaços / vazio / 81 caracteres → 400; acentos e emojis no nome gravados corretamente (utf8mb4).
- Mesmo nome+semestre → 409 também no PATCH, não só no POST.
- Provas passadas não aparecem; prova de hoje aparece.
- Nome com HTML (`<b>x</b>`) aparece como texto na página, não como HTML.
